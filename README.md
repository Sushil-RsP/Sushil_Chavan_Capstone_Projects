# AI & Machine Learning Capstone Projects

A collection of two end-to-end Artificial Intelligence and Machine Learning capstone projects, developed by **Sushil Chavan** as part of my B.Tech journey in Computer Science and Engineering (AI & ML).

This repository brings together project source code, datasets, screenshots, technical reports, presentations, and demonstration recordings.

---

## Projects

### 1. AIML-02: AI-Assisted Medical Imaging and Diagnosis System

An AI-powered medical imaging project focused on analyzing medical images and assisting in the identification of potential abnormalities.

**Project contents:**
- Datasets and sample medical scans
- Backend and frontend implementation
- Machine learning and image-processing components
- Model evaluation and testing resources
- Screenshots and project documentation
- Project presentation and demonstration recording

### 2. AIML-03: Large-Scale Personalized Recommendation Engine

A personalized recommendation system project focused on building a two-stage recommendation architecture for generating relevant recommendations.

**Project contents:**

- Recommendation system source code
- Data processing and workflow components
- Model files and Triton model repository
- Automated tests and benchmarking resources
- Screenshots and technical documentation
- Project presentation and demonstration recording
