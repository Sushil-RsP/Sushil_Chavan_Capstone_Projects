Key Engineering Insights

  • Stage 1 Candidate Retrieval: Reduces 9,742 catalog items to 100 high-affinity candidates in ~3ms using FAISS Inner Product vector search.
  • Stage 2 Heavy Re-Ranking: Evaluates complex user-item-context non-linear crosses and fine-tunes ranking for maximum CTR conversion.
  • Latency Budget: Full two-stage pipeline finishes in under 15ms (and <1ms on cache hits), well within production SLAs (<100ms).

Orchestration
