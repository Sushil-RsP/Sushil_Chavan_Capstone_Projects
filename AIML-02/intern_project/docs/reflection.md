## 2. Key Learnings & Engineering Challenges

- **Preventing Data Leakage in Clinical Datasets:**
  In medical imaging, multiple radiographs often exist for the same patient across time. Partitioning purely randomly at the image level causes massive data leakage where a model recognizes patient-specific anatomy rather than pathology. Enforcing patient-level hashing in `create_manifests.py` was vital.

- **Interpretability Pitfalls:**
  Heatmaps generated by Grad-CAM are often misconstrued by novices as ground-truth anatomical proof. Emphasizing in the interface that heatmaps merely indicate model filter sensitivity was a crucial design principle.

- **Safe Deserialization:**
  Loading PyTorch weights with `weights_only=True` protects against arbitrary code execution exploits present in pickle-based model formats.
