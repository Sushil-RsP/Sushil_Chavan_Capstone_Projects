# Data Directory

> **For education only — not for clinical use.**

## Overview
This directory holds dataset manifests, split files, and preprocessing
configuration. **No patient images, DICOM files, or large binary data
are stored here or committed to Git.**

## NIH ChestX-ray14

| Property | Value |
|----------|-------|
| License | NIH Open Access |
| Access | [nihcc.app.box.com](https://nihcc.app.box.com/v/ChestXray-NIHCC) |
| Images | 112,120 frontal-view X-rays |
| Labels | 14 disease labels + "No Finding" (multi-label, weak supervision) |
| Patients | 30,805 unique patients |

### Access Instructions
1. Visit https://nihcc.app.box.com/v/ChestXray-NIHCC
2. Agree to NIH Data Use Agreement
3. Download `images_001.tar.gz` ... `images_012.tar.gz` and `Data_Entry_2017.csv`
4. Extract to `data/raw/nih_chestxray14/`
5. Run `scripts/create_manifests.py` to generate patient-level splits

### Label Definitions
Labels are generated by NLP text mining on radiology reports — not by
trained radiologists reading individual images. False-positive and
false-negative rates are non-trivial. The label "No Finding" does not
guarantee a normal study.

### Uncertain Labels Policy
Entries where label confidence is below 0.5 (as in the original release)
are **excluded** from loss computation during training. This is
documented in `configs/classification.yaml`.

3. Extract to `data/raw/msd_lung/`
4. Run `ml/segmentation/prepare_dataset.py`

## Privacy and De-identification

- All images must be de-identified before any processing
- Do not upload any image to third-party services without explicit authorisation
- Patient names, IDs, and DICOM metadata must never appear in logs or API responses
- Retain data only as long as necessary and per your institution's data-retention policy
